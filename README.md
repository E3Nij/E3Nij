## 🧠 How My Brain Usually Works

```javascript
while (alive) {

    idea = findInterestingProblem();

    if (idea) {
        research(idea);
        design(idea);
        build(idea);
        breakIt(idea);
        fixIt(idea);
        improve(idea);
    }

    repeat();
}
```

There is probably a more efficient way to do this.

I have not found it yet.
